# DSA Checklist

Source of truth for the office-brief DSA block (~40 min, 2 timed problems per session — see
`learning-mode-and-office-brief` in the mentoring vault). Pull the next 2 unchecked problems in
order each session. **This is a sequence, not a schedule** — no module deadline, no calendar
pressure. If an office day doesn't happen, the list just picks up where it left off next time.

Modules are grouped by topic (not by calendar week) — each one opens with the patterns it trains,
so you know *what* a problem is testing before you open it, not just its name.

---
